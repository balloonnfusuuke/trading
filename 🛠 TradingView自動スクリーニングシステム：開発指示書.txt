🛠 TradingView自動スクリーニングシステム：開発指示書
1. プロジェクト概要
TradingViewのプライベートセッション（Cookie）を利用し、カスタムスクリーナーで抽出された銘柄リストとその詳細データ（価格、RSI）を朝４時４０分（米国市場が閉まるギリギリの時間）
に取得し、データフレーム化（またはCSV保存）するPythonシステムを構築する。

2. 技術スタック
Language: Python 3.x

Libraries: requests, pandas, datetime, time

3. 具体的な実装指示
Role: Expert Python Developer / Web Scraping Specialist

Task: > TradingViewの内部APIを叩き、自分のアカウントのセッションを利用して銘柄データを取得するスクリプトを作成してください。（おそらく米国株式のスクリーニング結果が出ていると思われる）

Requirements:

認証設定: sessionid を含むヘッダー（Headers）を構成し、認証済みのリクエストを送信すること。

現在値（close）
